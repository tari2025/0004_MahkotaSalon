MahkotaSalon - Aplikasi Pemesanan Layanan Salon
<br/>
 
MahkotaSalon adalah aplikasi Android yang dikembangkan untuk memudahkan pelanggan dalam melihat informasi layanan salon dan <br/>
melakukan pemesanan layanan secara online. Aplikasi ini dibangun menggunakan Jetpack Compose
dengan arsitektur MVVM dan terintegrasi dengan REST API (PostgreSQL).
